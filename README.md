AI Meeting Notes Automation

An AI-powered meeting notes automation built with n8n, Telegram, Google Sheets, Gmail, and JavaScript.

Overview

This automation processes meeting recordings uploaded through Telegram and converts them into structured meeting notes.

It automatically extracts important information such as:

- Meeting Summary
- Key Decisions
- Action Items
- Timestamp
- Chat ID
- Participant or Meeting Name

The extracted information is stored in Google Sheets and can also be sent to the user by email through Gmail.

Workflow

Telegram → Get File → AI Processing → JavaScript → Google Sheets → Telegram Confirmation → Gmail

Features

- 🎙️ Receive meeting recordings through Telegram
- 🤖 AI-powered meeting note extraction
- 📝 Generate structured summaries
- ✅ Extract decisions and action items
- 📊 Store meeting data in Google Sheets
- 📧 Send meeting notes through Gmail
- 💬 Send confirmation through Telegram

Technologies Used

- n8n
- AI / GPT
- Telegram
- Google Sheets
- Gmail
- JavaScript

Use Case

This automation can help businesses, teams, and professionals reduce manual note-taking and keep important meeting information organized for easy follow-up.
